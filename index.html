• git branch — показывает все ветки.
  • git branch new-branch — создаёт новую ветку.
  • git checkout new-branch — переходит на новую ветку.
  • git checkout main — возвращает на главную ветку.
  • git status — показывает изменения в файлах.
  • git add . — добавляет изменения для сохранения.
  • git commit -m "текст" — сохраняет изменения с названием.
  • git log — показывает историю коммитов.
  • git push origin HEAD — отправляет ветку на GitHub.
  • git pull — скачивает изменения с GitHub.
  • git push -u origin new-branch — отправляет новую ветку на GitHub и связывает её.
